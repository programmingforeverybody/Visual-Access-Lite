# QuickAccess.exe 🗄️

Lightweight Windows application for managing Microsoft Access databases easily.

---

## ✨ Features
- 📂 Load Access database (.accdb)
- 📋 Select and view tables
- 🔍 Execute SQL queries
- 💾 Save changes
- ⚡ Fast and lightweight interface

---

![App Screenshot](screenshot.png)

---

## 🚀 How to Use
1. Click "Select access database"
2. Choose your database file
3. Select a table
4. Write your SQL query
5. Click "Display" or "Save"

---

## 🛠️ Built With
- C#,VB.NET/ Windows Forms
- Microsoft Access

---

## 🎯 Purpose
This tool is designed to simplify working with Access databases in a fast and visual way.
